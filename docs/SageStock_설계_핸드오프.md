# SageStock — 앱 설계 & 와이어프레임 핸드오프

개인용 한국·미국 주식 분석 모바일 앱. 회원가입 없이 단일 사용자(관리자/개인)가 로그인해 사용한다. Android 기준, 기준 디바이스 Galaxy S25 Ultra(논리해상도 약 412 × 915dp), 세로형. 기술 스택은 Kotlin / Jetpack Compose 권장. 시각 톤은 화이트·실버·그레이 라이트 테마를 기본으로 하고 다크 테마를 옵션으로 둔다.

---

## 1. 정보 구조 (IA)

```
스플래시 (자동 로그인 판정)
├─ 로그인  ......................... 탭 없음 (세션 진입점)
└─ 메인 (하단 탭 5개)
   ├─ ① 홈/대시보드            [탭1]
   ├─ ② 종목 검색              [탭2]
   ├─ ③ 매매 시그널            [탭3]
   ├─ ④ 가상매매(포트폴리오)   [탭4]
   └─ ⑤ 설정                   [탭5]

공용 스택 (어느 탭에서나 push)
└─ 종목 상세
   ├─ 차트  탭
   ├─ 지표  탭  (차트/지표 화면과 컴포넌트 공유)
   ├─ 시그널 탭
   └─ 가상매매 탭 → 매수/매도 입력(바텀시트)

확장 슬롯 (AI)
└─ AI 예측  ─ 홈 'AI 후보' 카드 + 전용 화면(준비중/데이터부족/분석불가 빈상태)
```

설계 의도: AI 예측은 아직 모델 미연결 단계이므로 별도 탭을 차지하지 않고 홈·시그널의 확장 슬롯과 전용 화면으로만 둔다. 모델 연결 후 하단 탭으로 승격할 수 있도록 라우팅을 분리해 둔다. 종목 상세는 홈·검색·시그널·포트폴리오 모든 진입점에서 동일하게 push되는 공용 스택이다.

## 2. 하단 탭 네비게이션

| 탭 | 라벨 | 역할 | 진입 시 기본 화면 |
|----|------|------|------------------|
| 1 | 홈 | 대시보드 | 관심종목·장상태·시그널·상위 |
| 2 | 검색 | 종목 검색 | 검색창 + 최근 검색 |
| 3 | 시그널 | 매매 신호 피드 | 전체 종목 시그널 카드 |
| 4 | 가상매매 | 포트폴리오 | 총평가 + 보유종목 |
| 5 | 설정 | 환경·데이터·테마 | 그룹 리스트 |

상태바 ~44dp, 하단 탭 ~64dp 고정. 활성 탭은 brand 색(아이콘 채움 + 라벨 Semi Bold), 비활성은 tertiary.

## 3. 주요 사용자 플로우

- 분석: 홈/검색 → 종목 상세 → 차트·지표 ON/OFF → 시그널 탭 해석 → 관심종목 추가
- 가상매매: 종목 상세 → 가상매매 탭 → 매수/매도 입력 → 기록 저장 → 포트폴리오 성과 확인
- 로그인/세션: 스플래시 → 자동로그인? → (예) 홈 / (아니오) 로그인 → 실패 시 인라인 에러 · 설정>로그아웃 시 로그인 복귀
- AI 예측: 홈 'AI 후보' → AI 예측 화면 → (모델 OK) 추천 리스트·확률·근거 / (미연결) 빈 상태

## 4. 화면별 핵심 컴포넌트 & 텍스트 와이어프레임

상태: 기본 / 포커스 / 실패(빨강 에러) / 로딩(버튼 스피너) / 자동로그인 성공 시 화면 스킵.

[아이디        ]

비밀번호를 잊으셨나요? · 관리자에게 문의
```

### 02 · 홈 / 대시보드 [탭1]
컴포넌트: 헤더(앱명·날짜·알림), 장상태 배지(장중/프리·애프터마켓/장마감/지연), 시장 세그먼트(전체·한국·미국), 관심종목 행(스파크라인·등락), 오늘의 시그널 가로 카드, 상위 탭(상승률·거래량·AI 후보), AI 미리보기 슬롯.
상태: 로딩(스켈레톤) / 관심종목 없음 / 장마감(회색 배지) / 지연데이터 배너.

[전체|한국|미국]

 NVIDIA  US   ~~ $1,204.5 -0.94%
오늘의 주요 시그널          더보기 ›
[골든크로스·에코프로][데드크로스·NVDA] →
[상승률 상위|거래량 상위|AI 후보]

[홈][검색][시그널][가상매매][설정]

### 03 · 종목 검색 [탭2]
컴포넌트: 검색 입력, 시장 필터 세그먼트, 최근 검색 칩(개별/전체 삭제), 결과 행(종목명·티커·시장·＋추가 버튼/✓토글).
상태: 빈 입력(최근검색만) / 결과 없음 / 로딩 / 디바운스 자동완성.
```
[🔍 종목명·티커 검색       ]
[전체|한국|미국]
최근 검색           전체 삭제
[삼성전자 ✕][AAPL ✕][TSLA ✕]
검색 결과                12건
 삼성전자  KR·KOSPI  005930   [＋]
 Apple    US·NASDAQ AAPL     [✓]
```

### 04 · 종목 상세 (공용 스택)
컴포넌트: 뒤로가기, 종목 헤더+시장칩+지연/실시간 배지, 가격 블록(현재가·등락·OHLC·거래량), 내부 탭(차트/지표/시그널/가상매매), 캔들+시그널 마커, 기간 칩, 관심추가 ★.
상태: 실시간/지연/장마감 배지 분기, 데이터 로딩, KR(₩)·US($) 통화 포맷 자동.
```

78,400   ▲ 1,400 (+1.82%)
거래량 12.4M | 시가 77,200 | 고가 78,900 | 저가 76,800
[차트|지표|시그널|가상매매]
[ 캔들차트 + ▲골든 ▼데드 ◇다이버전스 마커 ]
[1D][5D][1M][3M][1Y][전체]
```

### 05 · 차트 / 지표 (상세 내부 + 전체화면 옵션)
컴포넌트: 기간 칩(1D·5D·1M·3M·6M·1Y·3Y·전체), 봉 세그먼트(일/주/월), 캔들+EMA(5·20·60·120)/볼린저 오버레이, RSI·스토캐스틱 서브패널, 지표 ON/OFF 토글, ⚙ 지표 설정 바텀시트.
설정 패널 값: EMA 기간, RSI 기간·과매수/과매도선(70/30), 볼린저(20·2σ), 스토캐스틱(%K/%D), 이격도(20일). 변경 시 설정 기본값에 저장.
상태: 가로모드 전체차트(옵션), 핀치 줌/팬, 십자선 툴팁, 데이터 부족 구간.
```
‹ 삼성전자·차트            [⚙ 지표설정]
[1D 5D 3M 6M 1Y 3Y]
[일봉|주봉|월봉]
[ 캔들 + EMA + 볼린저밴드 ]
보조지표                  ON/OFF
 EMA 5·20·60·120  ........ [ON]
 볼린저밴드 20·2σ ........ [ON]
 RSI 14·70/30 ........... [ON]
 스토캐스틱 14,3,3 ...... [OFF]
 이격도 20일 ............ [OFF]
```

### 06 · 매매 시그널 [탭3]
컴포넌트: 타입 필터 칩(전체·골든크로스·데드크로스·상승/하락 다이버전스), 시그널 카드(타입·발생일·기준지표·해석 문구·위험도 바), 종목 칩 → 상세 차트 마커 점프.
상태: 신규 NEW 배지, 빈 피드, 위험도 색상(낮음 초록·중간 앰버·높음 빨강).

[전체][골든크로스][데드크로스][상승 다이버전스][하락 다이버전스]
┌ 골든크로스           2026.06.05

│ 위험도 [▓▓░░░] 낮음
└
```

### 07 · AI 예측 (확장 화면)
컴포넌트: 베타 배지, AI 추천 카드(상승확률·예상상승률·신뢰도·근거지표·리스크요인·＋관심추가), 정렬.
빈 상태 3종: 준비중(모델 미연결), 데이터 부족(이력 60일 미만), 분석 불가(거래정지·상폐). 안내형 톤(일러스트+설명+액션).
```
AI 급등주 예측  [실험적]
┌ 한미반도체 KR        상승확률 72%
│ 예상 +8.5% | 신뢰도 중상
│ 근거: 거래량 급증·골든크로스·외국인 순매수
│ 리스크: 과열(RSI74)·실적 임박
│ [＋ 관심종목 추가]
└
--- 빈 상태 ---
[ AI 모델 준비중 / 데이터 부족 / 분석 불가 ]
```

### 08 · 가상매매 (Paper Trading)
입력(상세 탭/바텀시트) 컴포넌트: 매수/매도 세그먼트, 단가·수량 입력, 비율 퀵칩(10/25/50/최대), 주문 요약(금액·가상 예수금), 실행 버튼(매수 빨강/매도 파랑), "가상" 고지.
포트폴리오[탭4] 컴포넌트: 총평가/총손익 요약카드, 보유/히스토리 탭, 보유종목 행(평단·수량·평가금·평가손익·수익률), 히스토리 타임라인.
상태: 잔액 부족 / 보유 없음(매도 비활성·빈상태) / 입력 검증 에러 / 저장 토스트 / KR·US 통화 분리 합산.
```
가상매매 — 총 평가금액 12,480,000  +480,000 (+4.00%)
[보유종목|매매 히스토리]
 삼성전자  10주·평단74,000   784,000  +5.9%
 NVIDIA   2주·평단$1,250   $2,409   -3.6%
--- 입력 ---
[매수|매도]  단가 78,400  수량 10주 [10%|25%|50%|최대]
주문금액 784,000 / 예수금 9,216,000
[ 가상 매수 기록 ]  (실제 주문 아님)
```

### 09 · 설정 [탭5]
컴포넌트: 그룹 리스트(계정·데이터·차트 기본값·표시), 상태 인디케이터, 토글, 디스클로저 행, 로그아웃(빨강).
항목: 로그인 정보, 로그아웃 / 데이터 소스 상태(정상·지연·오류)·시장 표시·새로고침 주기 / 기본 차트 기간·기본 봉·기본 보조지표 / 테마(다크 우선)·상승하락 색상·통화 표시.
상태: 데이터 소스 정상/지연/오류, 테마 즉시 전환, 변경값이 차트 기본값에 반영.

## 6. 상태 매트릭스 (공통)

## 7. Figma 이관 가이드

- 페이지: `00 커버`, `01 IA·플로우`, `02 화면`, `03 컴포넌트` 4개 페이지 구성 권장.
- 토큰: 위 표를 Figma Variables(color/text/spacing/radius) 컬렉션으로 등록. 라이트/다크 두 모드를 Variable Mode로.
- 컴포넌트화 대상: 상태바, 하단 탭(5 variant·active state), 종목 행, 시그널 카드, 칩/배지(up·down·neutral·warning·success), 세그먼트 컨트롤, 토글, 입력 필드, 버튼(brand·up·down·outline), 빈 상태, 캔들 차트 플레이스홀더.
- 프레임 크기: 412 × 915, Auto Layout 수직, 좌우 패딩 16~18로 통일.

## 8. 현재 산출물 상태

- Figma 파일 생성 완료. **홈/대시보드, 설정** 2개 화면을 Figma에 생성(라이트 톤·실버/그레이).
- Figma Starter 플랜의 MCP 호출 한도에 도달하여 나머지 화면은 본 문서 + HTML 와이어프레임으로 제공.
- 한도 초기화 또는 플랜 업그레이드 후, 본 문서를 기준으로 나머지 7개 화면을 동일 스타일로 이어서 생성 가능.
